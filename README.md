**Source file       :**   sambvca21.f<br>
**Information       :**   Fortran source code to calculate buried volume and array of points 
                      defining the surface of the catalytic pocket. <br>
**To be compiled as :**   gfortran -o  sambvca21.x sambvca21.f<br>
**Input file        :**   Input file is myfile.inp, examples with instructions in the Examples directory.<br>
**Executed as       :**   sambvca21.x myfile      It automatically generates a myfile.out plus other output files<br>
<br>
**Script file       :**   plot_countourmap.py <br>
**Information       :**   Python script file to generate png and a ps images of the catalytic pocket with countur levels. The minimum and the maximum levels are determined automatically by the script, and are set as zmin = minimum value of x and y, and zmax = maximum z value in the input file.  This can be overridden by settin --zmin value and --zmax value at runtime. <br>
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x <br>
**Executed as       :**   plot_contourmap.py  myfile-TopSurface.dat levels-spacing (optional, --zmin value --zmax value).<br>
 <br>
**Script file       :**   plot_heatmap.py <br>
**Information       :**   Python script file to generate png and a ps images of the catalytic pocket as heatmap. <br>
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x <br>
**Executed as       :**   plot_heatmap.py  myfile-TopSurface.dat  <br>
 <br>
**Script file       :**   downsample_symmetrize_surface.py <br>
**Information       :**   Python script file to downsample the myfile-TopSurface.dat file and symmetrize maps <br>
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x <br>
**Executed as       :**   downsample_symmetrize_surface.py --map    myfile-TopSurface.dat  --symm   c1/c2/c2v/csx/csy --step   new-grid-step <br>
**Optional          :**  --keep   yes/not reduce or not the grid to minimal symmetry --deltag DeltaG-CSV-file-with-'ID,DeltaGexp' columns <br>
**Output file 1    :**    myfile-TopSurface_resample_symmetrized_step_N_NN.dat downsampled and symmetrized input file <br>
**Output file 2    :**    myfile-TopSurface_resample_symmetrized_step_N_NN.csv 1D flattened surface <br>
 <br>
**Script file       :**   prepare-input-bulkier-NE+.py <br>
**Information       :**   Python script file to read a sambvca output file and generate a sambvca input file that prevents molecule reorientation.  Vbur analysis performed on the exact geometry in input. However, coordinates handled so that bulkier +z octant is NE+z. <br>
**Input file        :**   Input file is standard myfile.out generated by sambvca21.x on myfile.inp<br>
**Output file       :**   Output file is myfile-SP.inp file that is input for sambvca. However, coordinates have been handled to have most buried z+ octant NE+z. <br>
**Executed as       :**   prepare-input-bulkier-NE+.py myfile.out  <br>
<br>
**Source file       :**   matrix-1-radius.f <br>
**Information       :**   Fortran code to read a 2 radii matrix file and rewrite a 1 radius matrix file<br>
**Information       :**   To be compiled as gfortran -o matrix-1-radius.x matrix-1-radius.f <br>
**Input file        :**   Input file is standard myfile.matrix <br>
**Executed as       :**   matrix-1-radius.x  < 2radii.matrix   > 1radius.matrix<br>
 <br>





**Examples         :**   Directory with examples. Check the README file there for further info
