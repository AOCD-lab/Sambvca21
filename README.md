**Source file       :**   sambvca21.f<br>
**Information       :**   Fortran source code to calculate buried volume and array of points <br>
                      defining the surface of the catalytic pocket.
**To be compiled as :**   gfortran -o  sambvca21.x sambvca21.f<br>
**Input file        :**   Input file is myfile.inp, examples with instructions in the Examples directory.<br>
**Executed as       :**   sambvca21.x myfile      It automatically generates a myfile.out plus other output files<br>
<br>
**Script file       :**   plot_countourmap.py
**Information       :**   Python script file to generate png and a ps images of the catalytic pocket with countur levels.
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x
**Executed as       :**   plot_contourmap.py  myfile-TopSurface.dat levels-spacing

**Script file       :**   plot_heatmap.py
**Information       :**   Python script file to generate png and a ps images of the catalytic pocket as heatmap.
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x
**Executed as       :**   plot_heatmap.py  myfile-TopSurface.dat 

**Script file       :**   downsample_symmetrize_surface.py
**Information       :**   Python script file to downsample the myfile-TopSurface.dat file and symmetrize maps
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x
**Executed as       :**   downsample_symmetrize_surface.py --map    myfile-TopSurface.dat 
                                                       --symm   c1/c2 (only c1 or c2 implemented now)
                                                       --step   new-grid-step
                                            Optional:  --keep   yes/not reduce or not the grid to minimal symmetry
                                            Optional:  --deltag DeltaG-CSV-file-with-'ID,DeltaGexp' columns
**Output files     :**    myfile-TopSurface_resample_symmetrized_step_N_NN.dat downsampled and symmetrized input file
**Output files     :**    myfile-TopSurface_resample_symmetrized_step_N_NN.csv 1D flattened surface

**Examples         :**   Directory with examples. Check the README file there for further info
