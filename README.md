**Source file       :**   sambvca21.f<br>
**Information       :**   Fortran source code to calculate buried volume and array of points 
                      defining the surface of the catalytic pocket. <br>
**To be compiled as :**   gfortran -o  sambvca21.x sambvca21.f<br>
**Input file        :**   Input file is myfile.inp, examples with instructions in the Examples directory.<br>
**Executed as       :**   sambvca21.x myfile      It automatically generates a myfile.out plus other output files<br>
<br>
**Script file       :**   plot_countourmap.py <br>
**Information       :**   Python script file to generate png and a ps images of the catalytic pocket with countur levels. <br>
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x <br>
**Executed as       :**   plot_contourmap.py  myfile-TopSurface.dat levels-spacing <br>
 <br>
**Script file       :**   plot_heatmap.py <br>
**Information       :**   Python script file to generate png and a ps images of the catalytic pocket as heatmap. <br>
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x <br>
**Executed as       :**   plot_heatmap.py  myfile-TopSurface.dat  <br>
 <br>
**Script file       :**   downsample_symmetrize_surface.py <br>
**Information       :**   Python script file to downsample the myfile-TopSurface.dat file and symmetrize maps <br>
**Input file        :**   Input file is myfile-TopSurface.dat generated by sambvca21.x <br>
**Executed as       :**   downsample_symmetrize_surface.py --map    myfile-TopSurface.dat  <br>
                                                       --symm   c1/c2 (only c1 or c2 implemented now) <br>
                                                       --step   new-grid-step <br>
                                            Optional:  --keep   yes/not reduce or not the grid to minimal symmetry <br>
                                            Optional:  --deltag DeltaG-CSV-file-with-'ID,DeltaGexp' columns <br>
**Output files     :**    myfile-TopSurface_resample_symmetrized_step_N_NN.dat downsampled and symmetrized input file <br>
**Output files     :**    myfile-TopSurface_resample_symmetrized_step_N_NN.csv 1D flattened surface <br>
 <br>
**Examples         :**   Directory with examples. Check the README file there for further info
